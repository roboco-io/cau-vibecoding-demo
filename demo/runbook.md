# 라이브 시연 순서

시연은 완성된 결과를 한 번에 생성하기보다, 학생이 목표를 제시하고 에이전트 결과를 실행·검증하며 다음 요청을 하는 과정을 보여 줍니다. 공개 시연에는 `examples/student.md`의 가상 학생만 사용합니다.

## 1. 자료 검색

검색의 목적을 먼저 정합니다. 목표 공고를 찾는다면 학생 경험과 요구사항의 차이를, 참고 이력서를 찾는다면 구성과 표현의 근거를, 후보 이력서를 검색한다면 사용자에게 제공받은 가상 문서와 조건을 사용합니다.

```text
AGENTS.md와 examples/student.md를 읽어 줘. 이번 시연에서 내가 정한 검색 목적에 따라 자료를 찾아 정리해 줘. 실제 웹 자료는 원문 링크와 확인 날짜를 research/에 남기고, 가상 자료는 예제임을 표시해 줘. 검색 결과에서 다음 프로젝트에 필요한 요구사항을 정리해 줘.
```

## 2. 포트폴리오 만들기

```text
examples/student.md와 research/의 결과로 portfolio/에 간단한 한국어 포트폴리오를 만들어 줘. 현재 경험과 앞으로 만들 프로젝트를 구분하고, 없는 실적은 쓰지 마. 로컬에서 실행한 뒤 모바일 화면과 링크를 확인해 줘.
```

## 3. 지원을 위한 프로젝트 구축

```text
목표 직무의 요구사항과 현재 포트폴리오를 비교해, 시연 안에 실행할 수 있는 작은 프로젝트 하나를 제안해 줘. 내가 선택한 프로젝트를 projects/ 아래에 구현해 줘. 실행 방법, 사용자 문제, 내가 배울 기술, 검증 방법을 README에 적고 핵심 동작을 테스트해 줘.
```

## 4. 포트폴리오에 반영하기

```text
실제로 만든 프로젝트와 검증 결과를 portfolio/에 반영해 줘. 문제, 구현한 기능, 사용 기술, 실행 방법, 테스트 근거와 다음 개선점을 보여 줘. 가상의 성과 수치를 추가하지 말고 프로젝트 링크가 동작하는지 확인해 줘.
```

## 마무리

학생에게 목표와 근거를 제공하면 에이전트가 구체적인 결과를 만들 수 있다는 점을 설명합니다. 최종 결과물의 정확성과 자신의 기여는 학생이 확인합니다. 실제 지원서를 제출하는 과정은 이 데모에 포함하지 않습니다.
