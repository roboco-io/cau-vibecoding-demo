# ADR-004: 조회 화면과 API를 연결하고 AI는 개발 도구로 사용한다

- 상태: 제안. 간단한 조회 화면 포함은 사용자 선택.
- 날짜: 2026-10-06.

## 맥락

DB 담당자는 처리 품질을, 분석 담당자는 경기·선수별 기록을 확인해야 합니다. 바이브 코딩 역량은 구현 과정에서 입증하며, 실행 중 AI가 데이터 값을 판단하는 것은 첫 목표가 아닙니다.

## 결정

화면은 조회 API만 사용합니다. 필터·데이터 목록과 품질 실행 기록을 제공하고, 빈 결과·누락 측정값·매핑 실패·API 오류를 구분합니다. 범용 챗봇·모델 예측·런타임 LLM 호출은 포함하지 않습니다.

운영 설계는 CloudFront의 정적 화면과 `/api/*` 경로를 분리합니다. API는 Cognito JWT를 검증하며 인증 응답을 캐시하지 않습니다. 브라우저에 DB 접속 자격이나 IAM 토큰을 전달하지 않습니다. 현재 가상 목업에는 로그인과 실제 API를 연결하지 않았습니다.

AI 코딩 에이전트는 설계 대안, 코드·테스트 초안, 디버깅을 돕습니다. 사람은 데이터 의미·기준·라이선스·코드 변경을 검토하고 기대값과 실행 결과를 대조합니다. 비밀 정보와 실제 구단 비공개 자료를 입력하지 않습니다.

## 대안

챗봇 조회는 자연어 접근이 가능하지만 추가 모델 비용과 결과 검증 범위를 늘립니다. Notebook만 제공하면 화면/API 유지보수 증거가 약합니다. 첫 버전은 명시적 필터와 고정 API로 완료 기준을 검증합니다.

## 결과와 재검토

실행 때 API 키가 필요하지 않고 오류가 재현 가능합니다. 자연어 조회가 실제 사용자 요구로 확인되면 읽기 권한과 결과 검증 정책부터 별도 결정합니다. AI 사용 기록은 비밀 정보 없이 판단·수정·테스트 결과를 요약하며 검증되지 않은 생산성 수치는 쓰지 않습니다.
