# ADR-002: 로컬 단일 앱과 SQLite를 사용한다

- 상태: 대체됨. [ADR-005](005-aws-serverless.md), [ADR-006](006-aurora-dsql.md)이 운영 설계를 대체합니다. 이 문서는 최초 로컬 설계 기록입니다.
- 날짜: 2026-10-06.

## 맥락

학생이 한 실행 환경에서 수집·검증·DB·API·화면의 연결을 이해하고 시연해야 합니다. 첫 범위는 경기 한 개, 단일 적재 실행입니다.

## 결정

Python으로 데이터 처리와 SQL 접근을 구현하고 SQLite에 저장합니다. FastAPI가 조회 API와 기본 HTML/CSS/JavaScript 화면을 함께 제공합니다. 적재는 별도 CLI 흐름이며 API 요청으로 다운로드나 쓰기를 실행하지 않습니다. 첫 버전은 루프백 주소에만 바인딩합니다.

구체적인 Python·라이브러리 버전은 구현 시 호환성을 확인한 뒤 잠급니다. 문서 단계에서 미검증 실행 명령을 제공하지 않습니다. 동시 적재는 지원하지 않고 단일 프로세스 실행을 전제로 합니다.

## 대안

| 대안 | 이점 | 비용 |
|---|---|---|
| PostgreSQL + 별도 프론트엔드 | 동시 쓰기·운영 확장, UI 구조화 | 서비스·빌드·환경 설정 증가 |
| Streamlit | 빠른 분석 화면 | API 유지보수 역량을 독립적으로 보여주기 어려움 |
| CSV + Notebook | 탐색이 간단 | DB 제약·조회 API·재적재 검증이 약함 |

## 결과와 재검토

설정 부담과 배포 요소를 줄이며 DB·API 역할은 유지합니다. 다중 사용자·동시 쓰기·원격 배포 요구가 생기면 PostgreSQL과 인증·운영 구성을 다시 결정합니다. SQLite의 실제 설정과 잠금 동작은 구현 테스트로 확인합니다.
