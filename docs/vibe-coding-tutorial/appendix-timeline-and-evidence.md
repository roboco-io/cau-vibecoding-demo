## 근거 파일

- [source-map.json](source-map.json): 실제 프롬프트, 메시지 ID, 타임스탬프, 도구 출력 기록 위치.
- [인터뷰](../../projects/diamonddb/docs/interview.md): 데이터·사용자·범위·추가 AWS/SQL 요구.
- [UI 검증](../../projects/diamonddb/docs/ui-mockup.md): 6→2→6, 빈 결과·키보드·해상도.
- [비용 결과](../../projects/diamonddb/docs/cost/estimate-results.json): 세 가지 DPU 가정의 계산 출력.
- [배포 Actions](https://github.com/roboco-io/cau-vibecoding-demo/actions/runs/37435360285): 당시 성공한 배포 실행.

원본 JSONL 전체를 저장소에 복사하지 않았습니다. 비밀값·개인정보·환경 경로를 제외하고 필요한 근거만 선별했습니다. 원본에는 `msg_` 형식의 메시지 ID가 있어 인덱스의 `last_log_message_uuid`에 그 값을 사용합니다.

## 다음 업데이트

튜토리얼 생성 직전의 배포 완료 메시지를 마지막 기준으로 삼습니다. 후속 실제 구현·DB 실험·AWS 배포가 새 장의 시작점입니다. 실제 DPU·시간·검증 결과를 확인하기 전에는 설계를 성공 사례로 추가하지 않습니다. 기존 7장은 자동으로 다시 쓰지 않고 새 장과 인덱스·근거 메타데이터를 갱신합니다.
