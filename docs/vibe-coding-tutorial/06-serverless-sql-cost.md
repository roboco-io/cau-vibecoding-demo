# 6장: SQL 요구를 지키며 AWS 서버리스와 비용 설계하기

> **시간**: AWS 요청 17:02:42, SQL 수정 17:04:40 KST. 실제 작업 시간 미측정.
> **비용**: AWS 리소스는 배포하지 않음. 아래 금액은 월 운영 가정이며 발생한 비용이 아님.
> **핵심 발견**: 서버리스 DB를 고를 때 핵심 요구와 비용 산정 단위를 먼저 확인합니다.

## 상황

로컬 실행 중심의 첫 설계에서 AWS 운영 설계로 방향이 바뀌었습니다. 운영 요구와 월 요청량을 설명한 뒤 SQL 필수 조건을 추가했습니다.

## 실제 프롬프트

```text
이 서비스를 AWS상에서 서버리스 아키텍처를 써서 구현하고 운영하는것으로 아키텍처를 개선해줘. 그리고 월 10만건의 요청이 있다고 가정하고 운영 비용도 산출해줘
```

AI가 DynamoDB를 제안한 뒤 사용자가 요구를 명확히 했습니다.

```text
요건에는 SQL사용이 필수이므로 DynamoDB대신 Aurora DSQL을 쓰는것으로 해줘
```

## 진행한 일

운영 구성을 CloudFront/S3 → HTTP API/Lambda → **Aurora DSQL**로 변경했습니다. 적재는 S3 manifest → SQS → Lambda, 인증은 Cognito Lite, 로그·사용량은 CloudWatch로 설계했습니다. DSQL의 관계형 테이블·JOIN·PK/FK·트랜잭션을 증거로 삼습니다.

공식 문서와 지역별 AWS Price List에서 서울 지원·단가를 확인했습니다. 미국 리전 예시를 서울 가격으로 사용하지 않았습니다. 같은 날 공식 문서는 FK 지원을 설명하고 있었으므로 오래된 ‘DSQL에는 FK가 없다’는 설명을 따르지 않았습니다.

작은 경기 파일의 전체 트랜잭션을 유지하되 앱의 변경 계획을 2,000행·8MiB이내로 제한하고 SQLSTATE 40001은 전체 재시도를 설계했습니다. 실제 DSQL의 호환성·SQL 실행·한도 검증은 아직 하지 않았습니다.

## 결과: 월 비용은 사용량 가정에 달림

| 항목 | 기본 가정 |
|---|---|
| API / 정적 요청 | 각각 100,000회, 총 200,000회 CloudFront |
| 조회 Lambda |512MiB·평균 200ms |
| 적재 |월 30회·1GiB·60초 |
| DSQL 활동 |API당 1DPU가정 + 월 20,000DPU |
| 저장·전송 |DSQL 2GB, S3 5GB, viewer 20GB |
| 로그인 |직접 로그인 100MAU |

서울 단가는 DSQL100만 DPU당$10, 저장 GB-month당$0.40 입니다. 무료량을 적용하지 않은 합은 **$6.32848012**, 무료량을 모두 쓸 수 있는 가정의 합은 **$0.862**입니다. API1회=1DPU는 고정 규칙이 아닙니다. 쿼리·읽은 자료·인덱스·FK·재시도에 따라 달라집니다.

계획용 환율 1,500원/$로 약 9,493원과 1,293원, VAT 10%까지 가정하면 약 10,442원과 1,422원입니다. 현재 환율이나 실제 청구서를 뜻하지 않습니다. [상세 산정](../../projects/diamonddb/docs/cost-estimate.md)과 [부록](appendix-cost-summary.md)을 참고하세요.

## 배운 점

‘월 10만 요청’만으로는 비용을 정할 수 없습니다. 응답 크기, SQL 처리량, DB 저장량, 적재와 폴링도 필요합니다. 무료량은 계정·조직의 다른 사용과 공유되므로 무조건 적용된다고 약속하지 않습니다. 추정 DPU는 구현 후 실측으로 바꿉니다.

## 직접 해보기

```sh
python3 projects/diamonddb/scripts/estimate_cost.py
python3 projects/diamonddb/scripts/estimate_cost.py --free-tier
python3 projects/diamonddb/scripts/estimate_cost.py --dpu-per-request 10
```

계산기는 저장한 단가와 가정만 읽고 AWS 에 접속하지 않습니다. DPU를 0.1·1·10으로 바꿔 비교하세요. FastAPI·DSQL 커넥터·CDK를 설치하거나 실제 AWS 배포를 수행한 튜토리얼이 아닙니다.
