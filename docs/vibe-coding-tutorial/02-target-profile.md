# 2장: 경력이 아닌 수행 능력을 설명하는 목표 프로필

> **시간**: 요청 기록 2026-10-06 16:44:13 KST. 실제 작업 시간 미측정.
> **비용**: 프로젝트 AWS 리소스 사용 작업 없음. AI 비용 미확인.
> **핵심 발견**: 목표 프로필은 앞으로 검증할 능력과 이미 수행한 성과를 구분해야 합니다.

## 상황

학생에게 존재하지 않는 경력을 붙이면 시연의 목적을 벗어납니다. 공고의 업무를 어떤 방식으로 수행할지 설명하고, 이후 프로젝트에서 증거를 추가할 자리로 프로필을 만듭니다.

## 실제 프롬프트

```text
라이브 코딩 데모니까 경력은 무시하고 이 채용 공고에 맞춞형 프로필을 먼저 만들어줘. 경력은 없이 어떤 일을 할 수 있는지를 어필하는 프로필이면 좋겠어. 그리고 바이브 코딩을 사용할 수 있는것을 어필해줘.
```

## 진행한 일

[가상 목표 프로필](../../portfolio/profile.md)에 다음 구조를 작성했습니다.

- 원자료의 누락·중복·오류를 점검하고 문제를 설명하기.
- 서로 다른 데이터의 필드·단위·식별자를 공통 DB 구조로 연결하기.
- SQL·조회 API·문서로 분석 담당자가 사용할 수 있게 만들기.
- AI와 작은 기능을 구현한 뒤 기대값과 실제 결과를 직접 비교하기.

바이브 코딩은 런타임 챗봇 기능이 아니라 개발 과정입니다. AI가 초안을 만들고 사람이 데이터 의미·완료 기준·검증 결과를 판단합니다.

## 결과

프로필 제목은 ‘구단 데이터를 신뢰할 수 있는 정보로 연결하는 통합 DB 개발자’입니다. 문서 첫머리에는 가상 목표 프로필이라고 표시하고 완료된 실적처럼 쓰지 않았습니다. 데이터 검증·매핑·재적재·조회 테스트를 나중에 연결할 증거로 남겼습니다.

## 배운 점

‘할 수 있다’는 표현을 실제 지원서에 쓰려면 수행 근거가 필요합니다.이 단계의 목표 문장을 실제 보유 능력으로 바꾸지 않습니다. 검증이 끝난 뒤 문제·본인 역할·실행 결과·한계를 추가합니다.
