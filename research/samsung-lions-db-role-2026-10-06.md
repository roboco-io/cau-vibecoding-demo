## 공고에서 확인한 사실

- 모집: 2026년 통합 DB 관리 계약직. 근무 평가에 따른 정규직 전환 가능성이 안내되어 있다.
- 역할: TrackMan·Hawk-Eye 원자료의 결측·오류를 확인하고 외부 파트너와 품질을 개선한다. 서로 다른 장비·시스템의 구조를 파악하여 통합 저장하고, 연결된 내부 서비스의 유지·개선을 지원한다.
- 필수 경력: DB와 연결되는 API 또는 앱을 개발·유지한 경험 3년 이상.
- 우대 경험: 트래킹 자료 처리와 분석용 내부 서비스 구축·연동.
- 근무지: 대구 삼성라이온즈파크 또는 경산 볼파크.

## 학생 학습 목표로 해석

이 공고는 경력직이므로 학생의 실습을 필수 경력 충족으로 표현하지 않는다. 장기 목표로 삼고, 현재 갖춘 역량과 앞으로 만들 증거를 구분한다.

| 직무 요구 | 학습할 역량 | 학생이 남길 수 있는 증거 |
|---|---|---|
| 원자료 품질 관리 | 결측·중복·범위 오류 탐지, 데이터 검증 | 오류를 포함한 가상 데이터와 검증 보고서 |
| 여러 장비 자료 통합 | 스키마 설계, 식별자·단위 정규화, 적재 | 두 입력 형식의 매핑 표, DB 구조, 재실행 가능한 적재 과정 |
| DB 연결 서비스 | SQL, API 설계, 실패 처리 | 조회 API, 실행 예시, 기능 검증 |
| 유지·개선 및 협업 | 변경 추적, 오류 원인 설명, 문서화 | 테스트·변경 이력, 데이터 사전, 문제 해결 기록 |

위 기술·증거는 공고를 학습 활동으로 바꾼 제안이며 공고가 특정 언어·DB 제품을 지정했다는 뜻이 아니다.
